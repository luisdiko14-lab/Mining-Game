QUICK QUESTIONS

Is Mining Game free?

Yes. The Windows downloads linked above are provided through the project's GitHub Releases.

Which download should I choose?

Choose Setup EXE for the easiest installation. Choose MSI for Windows Installer workflows, or Portable ZIP if you prefer extracting the game yourself.

Where can I report a bug?

Open an issue on the GitHub issue tracker and include what happened and how to reproduce it.

Is this Minecraft?

No. Mining Game is an original voxel sandbox inspired by block-building games. It uses its own project code and generated assets.
